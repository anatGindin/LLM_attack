# Replication Package: Vulnerabilities of LLM Code Generation

This repository contains the replication package for our study *“Vulnerabilities of LLM Code Generation.”* It includes datasets, scripts, and evaluation tools used to analyze the impact of adversarial and structural perturbations on code generated by LLMs.

---

## 📂 Repository Structure

### 1. Dataset
- `data/`: Contains the HumanEval tasks and associated prompts used for code generation.
- `data/raw_code/`: Original code generated by each model for all prompt types.
- `data/processed_code/`: Code with metadata including prompt type (original, function renaming, jailbreak) and template used.

### 2. Prompt Variants
- `prompts/`: Includes all adversarial and structural prompt templates:
  - **Original Prompts:** Clean HumanEval tasks.  
  - **Function Renaming Prompts:** Prompts where function names are altered to semantically confusing identifiers.  
  - **Jailbreak Prompts:** Prompts modified with adversarial instructions to manipulate model behavior.

### 3. Scripts
- `generate_code.py`: Generates code completions for each model and prompt type.  
- `judger.py`: Evaluates code for functional correctness and security, producing scores and detailed reasoning.  
- `analyze_all.py`: Aggregates results across models and prompt types, producing tables and figures for analysis.  
- `extract_users.py`: Utility script to extract model usage patterns from datasets (if applicable).

### 4. Figures
- Visualizations for results, including:
  - Model performance across clean and perturbed prompts.  
  - Functional correctness vs security severity.  
  - Attack-family analysis (behavioral, benign, structural).

### 5. Inefficient or Vulnerable Examples
- `inefficient_examples/`: Examples of code that exhibits inefficiencies or security vulnerabilities under different prompt conditions.
