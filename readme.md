# Replication Package: The Impact of Jailbreak Attacks on Inefficiencies in LLM-Generated Code
Large language models (LLMs) have transformed software development, with code generation tools now ubiquitous. A 2024 GitHub survey reports that 97\% of developers use these tools, fostering widespread but potentially misplaced trust. This reliance raises critical security concerns regarding model robustness under adversarial conditions.

We investigated vulnerabilities in code generated by code generation LLMs, focusing on jailbreak attacks that elicit insecure or malicious outputs. Our research includes various types of jailbreaking techniques attacking different LLMs, and compares the effects of all the attacks, producing one clear survey. Beyond surveying existing techniques, we propose novel strategies that expose undocumented weaknesses. Our empirical evaluation delineates the attack surface and informs defenses for secure AI-assisted coding.

This repository contains the replication package for our study *“Vulnerabilities of LLM Code Generation.”* It includes scripts and evaluation tools used to analyze the impact of structural and adversarial perturbations on code generated by LLMs.

---

## 📂 Repository Structure

### 1. Dataset
- `HumanEval/`: Contains the HumanEval benchmark tasks used for code generation.

### 2. Prompt Variants
- **Original Prompts:** Unmodified HumanEval tasks.  
- **Function Renaming Prompts (Structural):** Prompts with misleading or confusing function names.  
- **Jailbreak Prompts (Adversarial):** Prompts modified using adversarial templates to manipulate model behavior.

### 3. Scripts
- `generate_code.py`: Generates code completions for each model and prompt type.  
- `judger.py`: Evaluates generated code for functional correctness and security, producing numerical scores and reasoning.  
- `analyze_all.py`: Aggregates results across models and prompt types, producing tables and figures for analysis.  

### 4. Models Evaluated
- **CodeLlama-7B**  
- **CodeGemma-7B**  
- **DeepSeek Coder-6.7B**

### 5. Figures
- Visualizations for results, including:
  - Model performance across clean and perturbed prompts.  
  - Functional correctness vs security severity.  
  - Attack-family analysis (behavioral, structural, benign control).

## 📌 Reproduction Instructions

1. Install required dependencies:
```bash
pip install -r requirements.txt
```
2. Generate code for all models and prompt variants:
```bash
python generate_code.py
```
3. Evaluate generated code using the Gemini judger:
```bash
python judger.py
```
4. Analyze results and generate figures:
```bash
python analyze_all.py
```
